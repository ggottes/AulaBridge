# Supported models

`verified` — confirmed on physical hardware by a public project or by us.
`vendor` — decoded from the manufacturer's driver or app, not yet confirmed on hardware.
`partial` — recognised and read-only; writes disabled.
`unknown` — USB IDs known, protocol not available.

## Shared USB IDs

Several IDs are used by more than one model. VID:PID is never treated as proof of a model;
every connection runs the family's identity query first.

| VID:PID | Models sharing it |
| --- | --- |
| `0C45:800A` | S75 Pro, L99, F108 Pro, F75 Max, F98 Pro, S98 Pro, S99 Pro |
| `0C45:FEFE` | S75 Pro receiver, F87 Pro receiver, F75 HE receiver |
| `05AC:024F` | S75 Pro receiver, F108 Pro receiver, F75 Max receiver |
| `258A:010C` | all eight g5kb keyboards |
| `38A6:271x` | F87 Pro Sonix variants |
